Refrain — technical blueprint

Spec approved · Oct 3, 2026 Python 3.13 · Flask 3.1.3 Plain HTML/CSS/JS · localStorage Gemini 3.8 Flash · Vertex AI Cloud Run · us-central1 Canonical: devpost/spec.md

How the approved PRD gets built: a page in your browser that keeps your progress, a small Python server that holds the fixed rules and is the only part that talks to the AI, and Gemini, which writes the words but never decides the numbers.

How it works — tap a part

1The page in your browser

Shows the seven screens, runs the countdown and the chime, and keeps all your progress in localStorage — a sticky note the browser keeps for this one site. No accounts, no database.

2A small Python server

Flask on Cloud Run hands the page out and is the only part that talks to the AI. It holds the fixed rules: tap allowance, up / hold / ease back, and whether a roadmap obeys your survey.

3Gemini on Google Cloud

Writes the words — the roadmap reason, warm-up marks, feedback, two questions, your pattern, your rule. It never decides the numbers that move your roadmap.

Gemini, cost, and limits

One stateless call per job

Three jobs — roadmap, warm-up check, debrief — each one generate_content call with a JSON schema and thinking level medium (your choice at review). Nothing is stored for a later turn.

No API key

Locally: your Google sign-in. On Cloud Run: service account refrain-run with only roles/aiplatform.user.

Your data

Google won't use it to train or fine-tune models without permission. Prompts may be logged for abuse monitoring; request-response logging stays off.

client = genai.Client(enterprise=True, project=PROJECT, location="global",
                      http_options=types.HttpOptions(timeout=25_000))
response = client.models.generate_content(
    model="gemini-3.8-flash", contents=user_prompt,
    config=types.GenerateContentConfig(
        system_instruction=SYSTEM,
        response_mime_type="application/json",
        response_json_schema=schema,
        thinking_config=types.ThinkingConfig(thinking_level="medium")))   # checked in build step 1

What would it cost? estimate · checked during the build

Price period

Assumptions at thinking medium: about 2,000 input + 5,000 output tokens per session (≈ $0.02) and 800 + 1,800 per roadmap (≈ $0.007), at $0.75 / $3.75 per million tokens. How much medium thinks is unverified — the build measures it. The earlier ≈ $0.012 figure assumed lighter thinking; low is the fallback. Cloud Run hosting stays inside its monthly free tier (2 million requests, 180,000 vCPU-seconds, 360,000 GiB-seconds).

Guards on the public link

30 / hour per visitor

Per IP, before any AI call. Over it: “The coach needs a short break.”

360 Gemini calls / day

Whole service, retries included — about $3.60 at most per day at medium.

1 instance · $10 alert

Counters live in memory, so they stop bursts, not slow abuse. The budget alert emails you; deleting the service is the hard stop.

Where it will realistically break

Gemini slow or down

“The coach is thinking…”, one retry, then “The coach couldn't respond. Your work is saved.” with Try again. The roadmap change is already saved; the warm-up never blocks studying.

An answer breaks a rule

JSON-schema limits make it rare; code checks catch the rest and retry once. A roadmap falls back to the labelled default plan; a debrief shows Try again.

The public link gets hammered

Per-IP and daily caps answer “needs a short break”; one instance at most; the $10 alert emails you; one command switches it off.

Local sign-in expired

AI endpoints return 503 and the log says to run gcloud auth application-default login; the simulated coach keeps UI work going.

Decisions and open issues

Learner Your decisions
  • Stack: Python/Flask, plain HTML/CSS/JS, progress in localStorage, Gemini 3.8 Flash via Vertex AI with no API key — “đồng ý” (“agreed”).
  • Public link on Cloud Run in a new project refrain-coach-…, us-central1, “My Billing Account”, $10 alert — “có — tạo project mới, link công khai trên Cloud Run” (“yes, create a new project, with a public link on Cloud Run”).
  • Thinking level medium instead of the proposed low — “looks good. Suy nghĩ mid” (“looks good. Thinking: medium”). Deeper feedback for about $0.02 instead of $0.012 per session; low is the fallback.
  • Paid AI service and a separate new Google Cloud project (from 3-prd). The PRD's data notice now uses Vertex AI's real commitment: not used to train Google's models.
Agent proposal Details that follow from your choices — accepted with the spec
  • One model for all three jobs.
  • The roadmap change is applied when the debrief reaches the server, even if the AI fails.
  • Sessions per day = whole sessions that fit the daily minutes, capped at 6; shortest stage 2 minutes.
  • Pulled away with zero taps still gets a ready-to-resume rule — the end reason is a real event, not an invented pattern.
  • If the countdown hits zero while the End-early panel is open, the session counts as completed.
  • Limits: 30/hour per IP, 360 Gemini calls/day (lowered from 600 with medium, so a day still costs at most ≈ $3.60), 32 KB per request; one gunicorn worker; least-privilege service account.
  • Light theme only, with the dark focus screen as the exception. Open-source license chosen by you in 6-ship.
What was simplified and why
  • localStorage on one device instead of accounts and a database — the PRD keeps progress on this device.
  • Plain JavaScript, one page of hidden sections instead of a framework with routes — seven screens, no build step.
  • Fixed rules in Python; AI writes words only — progression must be exactly right and testable.
  • Templated roadmap sentence and edge-case lines — numbers and “not a focus lapse” can never be wrong.
  • In-memory rate limits on one instance instead of Redis or an API gateway.
  • Stateless AI calls, self-hosted fonts (no third-party requests), synthesized chime, a labelled simulated coach for tests — never in the demo.

The useful unknown

You asked which AI model Refrain uses, what it does, how many there are, and what it costs. Answer: one model doing three jobs, ≈ $0.012 per session at first, ≈ $0.02 now that you chose medium thinking. Check during the build: the server logs tokens for every call; after the first five real sessions we compare actual cost with the estimate and record it in checklist.md.
